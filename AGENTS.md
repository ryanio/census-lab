# Census workflow

Develop in a worktree based on the latest origin/main. Run the edition tests, regenerate any affected HTML, and verify the packaged site before integrating. Merge finished, verified work directly into main and push. Open a pull request only when Ryan requests one. Never force-push main.

Use the shared publication template and study registry for new editions. Keep PFP Census and Card Census as external links. Publish with the Publish Census workflow when requested and check the live project URL after deployment.
